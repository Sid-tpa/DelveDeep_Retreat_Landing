# Stillwater — Retreat Landing Page

A portfolio-ready retreat landing page concept inspired by a boutique wellness retreat brief.

## Project
**Delve Deep / Stillwater Retreat Concept**

The page demonstrates:
- Premium editorial retreat design
- Mobile-responsive landing page
- Retreat dates and availability
- Accommodation selection
- Private and shared room options
- Pricing and limited availability
- Retreat inclusions
- Daily schedule
- Registration form
- Kajabi-ready checkout handoff concept
- Confirmation/registration interaction
- Accessible, lightweight HTML/CSS/JavaScript structure

## Run locally

No Node.js, npm, or build process is required.

1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.

Optional local server:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Portfolio note

This is an original portfolio concept created from the supplied project brief. It is not an official Delve Deep or Kajabi website, and the imagery is represented with CSS artwork so the project remains self-contained.
